## ② 制作アプリの説明
グー・チョキ・パーから手を選び、3つあるHP(ハート)がゼロになったら負けの、CPUとの対戦型じゃんけんゲームです。

## ③ 工夫した点・こだわった点
生成画像を使って、冒険ゲームらしいデザインに仕上げました。

hoverとscaleで、マウスを重ねた際のエフェクトにもこだわりました。

なるべく簡略化したいと思い、背景からアバター、HPの枠など出来る限り一枚にまとめました。

ボタンも画像で作成したのですが、これはゲーム制作では邪道なのでしょうか...？

こだわりがあったり細かくデザインしたい場合はcssだけでは難しそうだと思ってしまいました。

## ④ 難しかった点・次回トライしたいこと
